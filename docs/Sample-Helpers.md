# Hanko helper classes

This note carries `cssclasses: wide, row-alt, img-grid`: a 50 rem text column, every second table row on the second surface, and images on one line as a grid.

## Other classes

- `max`: the full width of the pane.
- `table-wide`, `img-wide`, `wide-dataview`: only that element at 50 rem, centred over the text column.
- `table-small`: smaller tables.
